# Instructa Core

Lean, reusable anti-drift engineering core. It installs standalone and exposes exactly 11 public workflow skills:

1. `project-spec-packager`
2. `plan-ledger`
3. `architecture-ownership`
4. `duplicate-ownership-audit`
5. `hard-cut`
6. `root-cause-finder`
7. `search-context`
8. `test-ownership`
9. `security-boundary-review`
10. `code-review-gate`
11. `ship-gate`

Core is vendor-neutral and does not own kit/course routing, project-domain workflows, provider installs, or public agents.
