# Clarify

`clarify` makes complex technical material easier to understand and act on without
removing important detail.

## Install

```bash
npx skills add instructa/agent-skills --skill clarify -g
```

## Use

- Cursor and Claude Code: `/clarify <task>`
- Codex: `$clarify <task>`

Examples:

```text
/clarify Explain what this error actually means and what I should do.
/clarify Compare these options and recommend one.
/clarify Turn the previous answer into something I can approve or reject.
```

The skill keeps the facts and caveats that matter, removes jargon and repetition, and
makes the conclusion or next action visible.
